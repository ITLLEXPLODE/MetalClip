# MetalClip

Open-source game clip recorder for macOS. Captures a rolling buffer 
of gameplay and saves the last X minutes when you hit a hotkey — 
similar to Medal's instant replay or NVIDIA Shadowplay.

## Why?

Medal discontinued Mac support in 2018. macOS gamers deserve a 
modern, lightweight clipper built specifically for Apple Silicon.

## Tech Stack

- Swift 6
- ScreenCaptureKit (macOS 12.3+)
- AVFoundation
- AppKit (menu bar)

## Requirements

- macOS 13.0+
- Apple Silicon (M1 or later) recommended
